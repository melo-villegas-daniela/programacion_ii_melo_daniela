Programación 2

Repositorio correspondiente a la materia **Programación 2**.

En este repositorio se almacenarán proyectos, ejercicios, prácticas y subproyectos realizados durante el curso, principalmente utilizando **Python, Django y Odoo**.

---

## 🐍 Python

**Python** es un lenguaje de programación de alto nivel, conocido por tener una sintaxis sencilla y fácil de entender.

Durante la materia se utilizará Python para desarrollar programas, practicar programación orientada a objetos, trabajar con datos y crear diferentes proyectos.

---

## 🌐 Django

**Django** es un framework web desarrollado en Python que permite crear aplicaciones y sitios web de manera organizada y rápida.

Se utilizará para desarrollar proyectos web, trabajar con bases de datos, crear modelos, vistas y gestionar diferentes funcionalidades de una aplicación.

---

## 🧩 Odoo

**Odoo** es una plataforma empresarial de código abierto que permite desarrollar y utilizar diferentes módulos para gestionar procesos de una empresa.

Durante la materia se trabajará con Odoo y Python para conocer su estructura, crear módulos y personalizar funcionalidades.
